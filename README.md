# Perch（栖痕）

macOS 菜单栏剪贴板记录管理器：把与 LLM（AI Coding）交互过程中零散的复制动作，自动归拢成一组组**可整体回喂**的记录序列。

面向场景：LLM 交互中的**重复指令上下文**、**任务主干提示词与分支提示词**、**待处理任务队列**、**历史交互提示词**的成系列管理。

本工具是 [LLM-based-Software-Devlopment-Kit-Suite](https://github.com/zhyr/LLM-based-Software-Devlopment-Kit-Suite)（HaxiTAG）工具套件的一员。

## 解决的问题

与 LLM 多轮对话时，主提示词、追加指令、规则与约束、示例代码常常散落在剪贴板里，回头难以按任务主线重组。

Perch 的做法：

1. 自动监听剪贴板，把每次复制记为一个**分段（chunk）**，并记录来源应用与时间；
2. 把一段时间内相关的分段自动聚合为一棵**记录树（maintree）**，形成一组完整系列（如某次任务的"主干 + 分支 + 历史上下文"）；
3. 需要时一键**整树复制**回 LLM，标题与全部分段按时序拼接，保持提示词上下文不断裂；
4. 全部记录本地留存，支持搜索、归档、手工整理，随时复用。

## 数据模型

| 概念 | 含义 |
|------|------|
| 分段 chunk | 一次复制的内容：文本或图片 |
| 记录树 maintree | 一组相关分段的聚合 |

自动归类规则：距最近更新的分段 **60 秒内**的连续复制并入同一棵树；超时后自动另起一棵。也可手工**新建记录**、向已有记录**追加分段**、给记录**命名标题**。

## 功能特性

- **剪贴板自动采集**：0.5s 轮询，外部复制自动记录来源应用与时间；图片复制自动转 PNG 存档
- **便捷呼出**：菜单栏图标常驻 + 可拖拽悬浮面板，不抢焦点；全局快捷键（默认 `⌃⇧P`）显示/隐藏，`Esc` 隐藏
- **整体 / 单段复制**：单击记录复制整棵（标题 + 全部段按时序拼接）；单击分段仅复制该段，自身复制只更新时间戳、不重复入库
- **整理能力**：标题命名、归档/取消归档、全文搜索（内容与标题）、删除（可选二次确认）、一键清空
- **Markdown 归档**：每次变更自动生成小时事件日志 + 按天树状一览，方便在普通编辑器里人工回溯
- **多设备同步**：数据目录指向 iCloud Drive 等同步盘即可自动共享（见下）

## 使用技巧 / 快捷键

- **键盘导航（主列表）**：`↑` / `↓` 或 `J` / `K` 选择行；`回车` 复制整棵记录；`空格` 展开 / 折叠分段；`X` 切换归档；`⌫` 删除（按设置二次确认）
- **常用入口**：`⌘N` 新建记录；`⌘F` 搜索（输入即搜）；`Esc` 关闭面板；全局快捷键（默认 `⌃⇧P`）显示 / 隐藏
- **日期跳转**：点击底部日期区打开“有记录日期”目录，可直达任意日期或一键回到最新；翻页到旧屏后可快速返回
- **行操作**：按钮仅在悬停 / 展开 / 键盘选中时出现；右键记录可展开、复制整棵、复制最新分段、归档、追加分段、删除
- **删除默认开启二次确认**（设置页可关闭）；“清空全部”在设置页中，始终要求确认

## 数据与同步

- 默认存储于 `~/Documents/Perch`：`recordtree.sqlite`（数据主源）+ `images/`（图片附件）+ `markdown/`（归档）
- 设置 → 选择 iCloud Drive（或其它同步盘）文件夹即可迁移。目标为空 → 整体迁移；目标已有 Perch 数据（如其它设备的同步文件）→ 直接切换采用，本机旧目录保留
- 每台 Mac 用**同一 Apple ID** 选中**同一个 iCloud Drive 文件夹**即自动同步：应用每 2 秒检测数据文件远端变化并热重载
- 同步采用**整文件替换**（单文件 SQLite + `journal_mode=DELETE` 避免 WAL 旁文件损坏），**非字段级合并**：请勿让两台设备同时写入，冲突时为后写入者覆盖（last-writer-wins）

## 构建安装

要求 macOS 13+

```bash
swift build -c release        # 或直接运行 scripts/build_app.sh
bash scripts/build_app.sh     # 打包安装到 /Applications 并 ad-hoc 签名
```

启动后通过菜单栏图标或全局快捷键打开面板。
